# 🩸 Blood Post

### *Every story leaves a mark.*

A horror-themed, multi-author blogging platform built with the MERN stack. Blood Post combines the simplicity of blogging with social-platform-inspired features, wrapped in a dark, immersive interface.

## 🕸️ Features

- 📝 **Post Management** — Create, edit, publish, and delete posts.
- 📜 **Drafts & Publishing** — Write stories privately before making them public.
- 🔐 **Authentication** — Secure login and registration with JWT-based authentication.
- 🛡️ **Role-Based Access** — Separate permissions for users, admins, and the platform owner.
- 🏷️ **Categories & Tags** — Organize stories and discover content.
- 🎨 **Horror-Themed UI** — Dark aesthetics, crimson accents, and toxic-green highlights.
- ⚡ **Data Fetching** — Efficient server-state management with TanStack Query.

## ⚙️ Tech Stack

**Frontend:** React · Vite · Tailwind CSS · React Router · TanStack Query · Axios

**Backend:** Node.js · Express.js · MongoDB · Mongoose · JWT

**Infrastructure:** Redis · Git · GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- MongoDB or MongoDB Atlas
- Redis, if required by your backend configuration

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

Install dependencies:

```bash
cd backend
npm install

cd ../frontend
npm install
```

Configure the required environment variables in the backend and frontend environment files, following the configuration expected by the application.

Start the backend and frontend in separate terminals using their respective development scripts:

```bash
npm run dev
```

Open the local URL provided by Vite to explore Blood Post.
